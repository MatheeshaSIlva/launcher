# B-036: the Pixel shade tiles' symbols play Android 17's icon animations

Plan by the architect, 2026-10-24 (owner answers to its questions below, once given). Serves M2 (Pixel shade layout).

## Findings (QA and architect, emulator, Android 17 SystemUIGoogle read with dexdump and aapt2)
- Tile colours, corners (pill to 24 dp) and icon colour: Android animates them on Compose's default spring (stiffness
  1500, damping 1); ours on `motion.qs.tile-state` (0.16 s, damping 1, ~1542): they match.
- The difference: Android plays each tile icon's AnimatedVectorDrawable on every state change (`CommonTileKt.SmallTileContent`:
  `rememberAnimatedVectorPainter`, `atEnd` false after the first composition, then true; nothing plays on first show). Ours
  crossfades the static off and on glyphs over ~160 ms; the `pixel` icon set keeps each AVD's last frame.
- Android does not reverse an interrupted icon: a state change keys a new AVD played from its first frame (a jump; read from
  bytecode, moderate confidence).
- Interpolators: the extractor drops them (`extract_apk_vectors.py` line 134, every reference attribute). `anim/overshoot` =
  cubic (0.26, 1.5, 0.27, 1); `anim/ease_out` = cubic (0.5, 0, 1, 1); DND's path `M0,0 c0.4,0 0.2,1 1,1`; 0x7f01021a
  (Data Saver off) unresolved.

## Option A (chosen)
Export each AVD's animation into the icon set JSON and play it with a small pure player. Rejected: loading SystemUI's AVDs at
runtime (One UI has no Pixel SystemUI; bypasses icon sets), stretching the crossfade (not Android's choreography).

## Out of scope
Control Center with the pixel set (see Q2); sets without `play` keep the crossfade; Bluetooth's looping search icon; labels
(they crossfade on purpose; Android swaps them at once); the colour difference (B-046, see Q3); haptics; tile colours and
corners (they match).

- AC4 Nothing plays on panel open; a change while closed shows at rest.
- AC5 Sets without `play` crossfade exactly as before.
- AC6 No allocation while playing; no slice over 8 ms from symbols in the first toggle after install.
- AC7 `scripts/check.sh` green with the new tests.
- AC8 S24 (owner): looks as a Pixel's; `scenario_shade.sh` under Pixel no worse.

## Decisions (to log)
- An interrupted symbol reverses from where it is (Android restarts the other AVD: a jump, which rule 3 forbids).
- Animations are stored as tracks with cubic interpolators, normalised at build time; the player is pure and JVM-tested.
- A set without `play` keeps the crossfade; `NAME.off` unchanged.

## Slice 1 findings (2026-10-25, from SystemUIGoogle's dex)
- The large tile draws its icon through the same animated painter (`CommonTileKt.LargeTileContent` calls `SmallTileContent`):
  large and small tiles both animate.
- `BluetoothTile`: on and connected `qs_bluetooth_icon_on`; on, not connected, transient `qs_bluetooth_icon_search`; on, not
  connected `qs_bluetooth_icon_disconnected` (150 ms, starts with the earbud circles and no slash); off `qs_bluetooth_icon_off`.
  Off to on with no device therefore jumps on Android (the off icon ends on the slash). Ours: `bluetooth.off` plays (its first
  frame is the plain glyph), `bluetooth` has no play and crossfades from the slash (rule 3: no pop).
- The extra-dim tile uses `qs_extra_dim_icon_on/off`; our set still takes AOSP's static `ic_reduce_bright_colors`. Out of
  scope here (logged with B-036's follow-ups).
- An animator with no interpolator eases as `AccelerateDecelerate` (0.5 - 0.5 cos(pi t)): written `"e": "accdec"`.
- aapt2 dumps `fillType`, `strokeLineCap`, `strokeLineJoin` as numbers and the static code compares names: every APK-sourced
  static symbol draws butt caps, miter joins and non-zero fill (B-047, a visible change, for the owner).

## Notes for slices 2-3 (slice 1's reviewer, 2026-10-25)
- Bluetooth plays only toward off: from rest, turning on crossfades; turning on in the middle of the off play reverses it
  (its first frame is the on look at rest).
- The refusal rule compares tracks of one property only: refuse a group moved both along a motion path and by
  translateX/translateY (no shipped icon does).
- The continuity printout matches paths by name (Auto-rotate's 21.5 and Data Saver's 2 unmatched are naming, not jumps):
  judge from slice 3's frames.
- `IconSets.read` parses the whole file (124 KB) at once: load each play on its first use, off the drawing thread, and
  measure the first read on the S24.
- When B-047 is fixed, the end-of-play check compares cap, join and fill too.
